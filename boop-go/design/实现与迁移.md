# Boop Go 实现计划

## 文档说明

本文档记录 Boop Go 项目的实现计划和开发路线图，基于 Go + Gio + gvcode 技术栈进行开发，使用 gvcode 作为核心编辑组件。

---

## 项目概述

Boop 是一款跨平台的文本处理工具，核心特性包括：
- **拖拽文本处理**：用户可以将文本拖入窗口或从剪贴板获取
- **可定制的脚本片段**：用户可编写 Python 脚本对文本进行转换
- **即时反馈**：脚本执行后立即显示结果

本项目基于 Go + Gio + gvcode 构建，使用 gvcode 作为核心编辑组件，通过集成高性能的编辑器组件和脚本执行系统，实现一个轻量级、高性能的文本处理工具。

---

## 技术栈

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 后端 | Go | 高性能、跨平台、简洁高效 |
| 前端 | Gio | 响应式、跨平台、Go 原生 GUI 框架 |
| 文本编辑器 | gvcode | 高性能、轻量级代码编辑器组件 |
| 脚本执行 | `os/exec` | 安全、隔离、跨平台 |
| 序列化 | encoding/json | 配置管理 |
| 构建工具 | Go Build | Go 官方构建工具 |

## 验收标准

- Go 版本功能与 Python 版本完全对等
- 无阻断性 bug
- 基本测试通过
- 二进制体积 < 15 MB

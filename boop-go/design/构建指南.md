# Boop Go - 构建和测试指南

## 脚本清单

| 脚本 | 功能 | 使用方法 |
|------|------|----------|
| `build.sh` | 跨平台构建和打包 | `./build.sh --macos` |
| `test_app.sh` | 运行已编译的应用 | `./test_app.sh` |

---

## build.sh - 构建脚本

用于编译和打包 Boop Go 应用到不同平台。

### 功能特性

- 自动检测当前操作系统
- 支持 macOS/Linux/Windows 三平台构建
- 自动优化二进制文件大小（strip）
- 打包为平台特定格式（.dmg/.tar.gz/.zip）
- 显示构建产物大小信息

### 使用方法

```bash
# 为当前平台构建（Release 模式）
./build.sh

# 为特定平台构建
./build.sh --macos          # macOS
./build.sh --linux          # Linux
./build.sh --windows        # Windows

# 组合使用
./build.sh -m -v            # macOS 并显示详细输出
./build.sh -l -d            # Linux Debug 模式
./build.sh -c               # 仅清理构建产物

# 查看所有选项
./build.sh --help
```

### 构建产物

| 平台 | 输出文件 | 说明 |
|------|---------|------|
| macOS | `dist/Boop-<version>-macos-<arch>.dmg` | DMG 安装包 |
| macOS | `dist/Boop.app` | 应用包（不选 DMG 时） |
| Linux | `dist/Boop-<version>-linux-<arch>.tar.gz` | 压缩包 |
| Windows | `dist/Boop-<version>-windows-<arch>.zip` | ZIP 包 |

## test_app.sh - 测试脚本

用于运行已编译的应用程序，方便测试。

### 功能特性

- 自动检测二进制文件是否存在
- 支持 Debug/Release 两种模式
- 可选自动编译再运行
- 显示版本和路径信息

### 使用方法

```bash
# 运行 Release 版本（默认）
./test_app.sh

# 运行 Debug 版本
./test_app.sh --debug

# 先编译再运行
./test_app.sh --build
./test_app.sh --build --debug

# 查看帮助
./test_app.sh --help
```

## 自定义构建

### 修改版本

编辑 `go.mod` 中的版本信息：

```go
module boop-go

go 1.20

// 版本信息可以在构建脚本中定义
```

### 交叉编译

#### macOS → Linux

```bash
# 构建
GOOS=linux GOARCH=amd64 go build -o dist/boop-linux main.go
```

#### macOS → Windows

```bash
# 构建
GOOS=windows GOARCH=amd64 go build -o dist/boop-windows.exe main.go
```

## 故障排除

### 问题：未找到 go

```
[ERROR] Go 工具链未安装
```

**解决方案：**

```bash
# 下载并安装 Go
brew install go

# 或从官网下载安装包
# https://golang.org/dl/
```

### 问题：构建失败

```
[ERROR] macOS 版本构建失败
```

**排查步骤：**

1. 查看详细输出：`./build.sh -m -v`
2. 清理后重试：`./build.sh -c && ./build.sh -m`
3. 检查 Go 版本：`go version`（需要 1.20+）

### 问题：二进制不存在

```
[ERROR] 未找到编译后的二进制文件
```

**解决方案：**

使用 `--build` 参数自动编译：

```bash
./test_app.sh --build
```

## 最佳实践

### 开发阶段

```bash
# 1. 快速运行测试
go run main.go

# 2. 查看编译警告
go build -v

# 3. 格式化代码
go fmt
```

### 测试阶段

```bash
# 1. 编译优化版本
go build -ldflags="-s -w" -o boop main.go

# 2. 运行测试
./test_app.sh

# 3. 运行单元测试
go test ./...
```

### 发布阶段

```bash
# 1. 清理旧产物
./build.sh -c

# 2. 构建 macOS 版本
./build.sh -m

# 3. 检查产物大小
ls -lh dist/
```
